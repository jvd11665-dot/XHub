# XHub — Free Roblox Script Hub

**One loadstring. Free key. Multiple games. Clean UI.**

XHub is a free all-in-one Roblox script hub with auto game detection, regular updates, and Discord support (Mini-AI + tickets).

---

## Official loadstring

`lua
loadstring(game:HttpGet("https://xhub.blog/xhub-boot.lua"))()
`

---

## How to use

1. Get a **free 24h key** → [https://xhub.blog/get-key](https://xhub.blog/get-key)
2. Join Discord if asked → [https://discord.gg/cgRsTMUa9J](https://discord.gg/cgRsTMUa9J)
3. Open your executor in a **supported game**
4. Paste the loadstring and execute
5. Enter your key in the hub UI
6. Enjoy

Full guide: [https://xhub.blog/tutorial.html](https://xhub.blog/tutorial.html)

> **Note:** Use **Get Key** only (/get-key). Do **not** open private unlock / portal links — those show “Accès refusé” without a checkpoint.
